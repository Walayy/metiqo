## Intégrité et limites

`manifest.json` indique pour chaque capture son URL, sa date de lecture, son viewport, les tailles et les empreintes SHA-256. `checksums.json` couvre tous les autres fichiers de ce dossier après mise en forme. 002 et 003 ont subi une limite de transfert à 2000 nœuds ; ils ne prouvent pas un DOM complet. 004 corrige la méthode par lots de 500 nœuds avec vérification du nombre final. Les documents enfant des iframes n’ont pas de géométrie DOM détaillée exportée ; le texte AX peut les inclure. Le texte éditorial hors périmètre est expurgé, sans retirer les mesures des nœuds concernés.

014 porte le nom initial « mobile-map1 », mais son image correspond encore à la recherche sans résultat ; 015 est le relevé mobile avec les marchés rétablis. 016 est un instantané pris après redimensionnement : la position intermédiaire de la sidebar ne certifie pas un état responsive stabilisé. Les captures `principal-repeat` servent à distinguer le contenu initial et les éléments chargés ensuite.

Le code de lecture est conservé comme documentation textuelle dans `capture-method.js.txt` et `market-method.js.txt`. Il dépend des objets de la session navigateur ; il ne constitue pas un collecteur autonome à lancer.
