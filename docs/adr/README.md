# Décisions d’architecture

Un ADR court est obligatoire avant toute remise en cause d’une décision structurante listée dans la section 33 de la SFG. Cela couvre notamment la source Oracle’s Elixir, l’immutabilité des données et décisions publiées, le cutoff temporel, la séparation du modèle indépendant des cotes, la validation temporelle, l’abstention, l’absence de pari réel ou de scraper Stake, la simplicité de l’infrastructure et l’identité des contrats mock/réel.

Copier `0000-template.md`, attribuer le prochain numéro disponible et remplacer le titre. Le statut initial est `Proposé`. Une décision ne devient applicable qu’après passage à `Accepté` et mise à jour de la documentation affectée. Un ADR accepté n’est jamais réécrit pour masquer une évolution : une nouvelle décision le remplace explicitement.
